# Platform marks (W-140)

Single-path SVGs on a 24 grid, used by the platform icons (github, windows, macos, linux, android, ios)
to show where Viaalink runs. github, apple, linux, android and caddy come from simple-icons 13.21.0 (CC0 paths);
windows is the plain four-pane mark drawn here. The marks are trademarks of their owners — we use them
only to say "works on", never altered beyond colour and extrusion.
